Windows 10 连接 Windows XP 共享打印机完整指南

发表于2026-10-08|更新于2026-10-08|设备维修
|总字数:581|阅读时长:1分钟|浏览量:

有时在企业或家庭网络中，需要从 Win10 电脑连接老旧 WinXP 设备共享的打印机。本文将详细介绍具体的配置步骤。

一、Windows 10 客户机配置

1. 启用 SMB 1.0/CIFS 客户端

Windows XP 使用老旧的 SMB 1.0 协议进行文件共享，而 Win10 默认已禁用该协议，需手动开启：

  1. 打开 控制面板 → 程序和功能
  2. 点击左侧 启用或关闭 Windows 功能
  3. 勾选 SMB 1.0/CIFS 客户端
  4. 点击确定后 重启电脑

2. 允许”不安全来宾登录”

Win10 专业版（通过本地组策略）

  1. 按 Win + R，输入 gpedit.msc 并回车

  1. 依次展开：计算机配置 → 管理模板 → 网络 → Lanman 工作站
  2. 双击 启用不安全的来宾登录，选择 已启用
  3. 点击确定保存

3. 关闭密码保护共享

为了简化连接过程，需要关闭密码保护共享：

  1. 打开 控制面板 → 网络和共享中心
  2. 点击左侧 更改高级共享设置

  1. 展开 所有网络 选项

  1. 在底部找到 关闭密码保护共享，选择 关闭

二、Windows XP 共享主机配置

1. 设置本地安全策略

打开 本地安全策略，在 安全选项 中进行以下设置：

策略项 设置值
网络访问：本地账户的共享和安全模型 仅来宾 - 本地用户以来宾身份验证
账户：来宾账户状态 已启用

提示：如果”来宾账户状态”显示”不适用”，请在 CMD 中运行以下命令激活：

2. 设置打印机权限

  1. 打开 打印机属性
  2. 切换到 安全 选项卡
  3. 点击 添加，输入 Everyone
  4. 为 Everyone 账户勾选 允许打印 权限
  5. 点击确定保存

三、连接打印机

完成以上所有配置后，在 Win10 中：

  1. 打开 设置 → 设备 → 打印机和扫描仪
  2. 点击 添加打印机或扫描仪
  3. 系统将自动搜索网络中的共享打印机
  4. 找到对应的 WinXP 共享打印机，点击添加即可

总结：Win10 连接 WinXP 共享打印机的关键在于三点——启用 SMB 1.0 协议、允许来宾访问、关闭密码保护。按照本文步骤操作，即可顺利完成连接。
